# SKINDOC

## Project Overview
SKINDOC is a Java and Kotlin based Android application designed to help users with skincare routines by providing personalized recommendations, tracking progress, and educating users about various skin types and conditions.

## Features
- **Personalized Recommendations**: Tailored skincare routines based on user input.
- **Progress Tracking**: Users can track their skincare journey, log products used, and monitor results over time.
- **Educational Resources**: Comprehensive information about different skin types, conditions, and treatment options.
- **User Community**: Connect with other users for tips and experiences.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Rudraksh2605/SKINDOC.git
   cd SKINDOC
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the application on an Android device or emulator.

## Usage
- Launch the application.
- Follow the onboarding process to set up your skincare profile.
- Start logging products and track your skincare routine progress.
